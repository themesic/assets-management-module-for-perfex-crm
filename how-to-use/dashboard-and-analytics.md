# 📊 Dashboard & Analytics

The **Assets Dashboard** gives you a real-time overview of your asset inventory, key metrics, and quick actions. Use it to spot issues and take action fast.

---

## 1. 📍 Access Dashboard

**Navigation:** **Assets** → **Dashboard** from the sidebar (usually the first menu item).

---

## 2. 📈 Key Metrics (KPIs)

| Metric | Description |
|--------|-------------|
| **Total Assets** | Count of all assets |
| **Total Asset Value** | Sum of (quantity × unit price) for all assets |
| **Currently Checked Out** | Number of assets currently checked out |
| **Overdue Checkouts** | Checkouts past expected return date |
| **Pending Reservations** | Reservations awaiting approval |
| **Maintenance Due Soon** | Maintenance scheduled in the next 7 days |
| **Warranties Expiring** | Warranties expiring in the next 30 days |
| **Recently Added (7 days)** | Assets created in the last 7 days |

---

## 3. 📉 Depreciation Summary

- **Original Value** — Total purchase value
- **Total Depreciation** — Accumulated depreciation to date
- **Current Book Value** — Original minus depreciation

---

## 4. 📊 Charts & Breakdowns

### Assets by Status

- Not Used Yet, In Use, Liquidation, Warranty/Repair, Lost, Broken
- Visual breakdown (e.g., pie or bar chart)

### Assets by Group

- Count per asset group (e.g., Laptops: 25, Furniture: 40)
- Helps identify largest categories

### Assets by Location

- Count per location
- Useful for multi-site or warehouse management

---

## 5. 📋 Recent Activity

- Latest asset-related actions
- Who did what, when
- Link to view full audit log

---

## 6. 📅 Upcoming Maintenance

- List of maintenance scheduled in the next 7 days
- Quick link to maintenance records
- Helps plan workload

---

## 7. ⚡ Quick Actions

Common shortcuts, e.g.:

- **New Asset**
- **Check Out Asset**
- **New Reservation**
- **Schedule Maintenance**
- **Generate Report**

---

## 💡 Tips

- ✅ **Check dashboard daily** for overdue checkouts and maintenance due
- ✅ **Use quick actions** to save time
- ✅ **Monitor warranties** to plan replacements
- ✅ **Track recently added** to ensure new assets are properly configured
