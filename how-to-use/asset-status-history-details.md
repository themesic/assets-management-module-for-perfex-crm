# 📋 Asset Status History Details

The Asset Status History Details feature provides comprehensive information about each lifecycle event in an asset's journey. This detailed view allows administrators to access complete records of all asset activities, including allocations, revocations, maintenance, and other status changes with full contextual information.

<figure><img src="../.gitbook/assets/Screenshot from 2025-06-03 18-00-05.png" alt=""><figcaption><p>Asset Status History</p></figcaption></figure>

### 1. Access History Details

**From Asset Detail Page**: Navigate to any asset and click on the "History" tab to view all lifecycle events. Click on any history entry to open detailed information.

**From Asset Status History Section**: Go directly to Asset Status History section, select any record, and click "View Details" or use the details tab
