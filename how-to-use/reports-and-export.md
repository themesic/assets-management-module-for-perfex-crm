# 📈 Reports & Export

The Assets module includes comprehensive reporting. Generate reports for assets, depreciation, maintenance, checkouts, audit logs, and utilization — then export to **PDF**, **Excel**, or **CSV**.

---

## 1. 📍 Access Reports

**Navigation:** **Assets** → **Reports** from the sidebar.

---

## 2. 📋 Available Reports

| Report | Description | Use Case |
|--------|-------------|----------|
| **Assets List** | All assets with details | Inventory audit, export to accounting |
| **Depreciation** | Depreciation values, residual value | Financial reporting, tax |
| **Maintenance** | Maintenance schedule and history | Compliance, vendor management |
| **Checkout** | Check-in/out history | Usage tracking, overdue follow-up |
| **Audit** | Complete activity trail | Compliance, security review |
| **Utilization** | Asset usage rates, allocation % | Optimization, capacity planning |

---

## 3. 🔧 Using Reports

### Steps

1. Go to **Assets** → **Reports**
2. Select the **Report Type**
3. Apply **Filters** (optional):
   - **Group** — Asset category
   - **Location** — Storage location
   - **Status** — Asset status
   - **Date From / Date To** — For time-based reports
4. Select **Format**: PDF, Excel, or CSV
5. Click **Generate Report**

### Output

- **PDF** — Opens in browser, can be printed or saved
- **Excel** — Downloads as .xls file
- **CSV** — Downloads as .csv for import into other systems

---

## 4. 📊 Report Details

### Assets List Report

- Asset code, name, group, location, department
- Quantity, unit price, purchase date
- Warranty period, status

### Depreciation Report

- Asset code, name, purchase date
- Original value, depreciation period, months used
- Depreciation value, residual value, percentage

### Maintenance Report

- Maintenance records with asset, type, scheduled date
- Status, cost, vendor
- Filter by status, date range, asset

### Checkout Report

- Checkout records with asset, user, dates
- Status (checked out, returned, overdue)
- Filter by status, date range

### Audit Report

- All asset-related actions
- Who, when, what changed (old vs. new values)
- Filter by asset

### Utilization Report

- Asset usage statistics
- Total days owned vs. days used
- Utilization rate, allocation rate, checkout count

---

## 💡 Best Practices

- ✅ **Run depreciation report** regularly for accounting
- ✅ **Export audit log** for compliance reviews
- ✅ **Use filters** to focus on specific groups or periods
- ✅ **Save PDFs** for record-keeping and audits
