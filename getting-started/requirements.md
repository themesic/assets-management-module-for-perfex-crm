# ⚡ Requirements

### 🔧 System Requirements

To use the Assets Management Module, you need:

| Requirement | Version |
|-------------|---------|
| **Perfex CRM** | 2.3.* or higher |
| **PHP** | 8.0 or higher |
| **MySQL** | 5.6 or higher |

### 📦 Optional (for full functionality)

- **Cron job** — For automated notifications (warranty expiry, maintenance due, overdue checkouts)
- **cURL** — For webhook delivery
- **GD/ImageMagick** — For QR code and barcode generation

### ✅ Pre-Installation Checklist

1. Ensure Perfex CRM is installed and up to date
2. Verify your PHP version: `php -v`
3. Confirm MySQL is running and accessible
4. Have your Envato license key ready for activation

That's all you need to get started! 🚀
